# Пушистый друг

Лендинг для продажи котят и щенков. Сверстан на HTML и CSS без фреймворков и библиотек.

https://dezz1203.github.io/landing-page/

Структура проекта
На странице три смысловых блока. В первом экране приветствие с круглыми фото котенка и щенка и кнопкой перехода к каталогу. 
Дальше карточки питомцев — два котенка и два щенка. У каждой карточки фото, имя, возраст, описание, цена и кнопка связи.
Внизу форма обратной связи с полями имени и телефона.

Особенности
Страница адаптивная. На мобильных разрешениях карточки перестраиваются в одну колонку, форма сжимается, шрифты уменьшаются.
Использованы CSS Grid для карточек и Flexbox для шапки и формы. Изображения взяты с Unsplash.
